# PostaHop

Logistics routing MVP: packets moving across **nodes** and **vehicles**, with
transfers vehicle→node and vehicle→vehicle ("in-flight hops"), geographic route
analysis (travel time, traffic, delay, ETA) and financial viability analysis.

MVP goal: validate the **routing algorithms, the API and financial viability**
(delays, reroutes, costs). No end-user app yet; only a simple viewer for
simulation results.

## Stack

| Concern | Choice | Decision |
|---|---|---|
| Language | Python 3.12 (simulation, analysis, pilots, API) | ADR-0002 |
| API | FastAPI, deployed on Vercel | ADR-0002 |
| Results viewer | Static HTML reports (Plotly charts + Leaflet maps) generated by simulation runs | ADR-0002 |
| Database | Supabase (Postgres + PostGIS) | ADR-0001 |
| VCS, CI/CD | GitHub + GitHub Actions | ADR-0001 |
| Task tracking | GitHub Issues + GitHub Projects | ADR-0004 |

## Layout

```
├── .claude/agents/      # Specialist agents: architect, algorithms, engineer, docs-writer

```
